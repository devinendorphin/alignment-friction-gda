Subject: Phase 4D v4.4.1 Repair Run — Refusal Capture Confirmed, Option C Preserved
Council,
The Phase 4D repair run has now completed through v4.4 and v4.4.1. The repair objective was not to redesign the assay, but to determine whether the prior v4.3 failure modes were bookkeeping artifacts, provider errors, bank-construction effects, or genuine model-level refusal/missingness behavior.
The short version is: the repair worked, and the signal sharpened.
v4.4 produced a complete 250-row matrix: 5 conditions × 5 substrate models × 10 repair-bank quadruples. The gate posture remained Option C: architecture discrimination is audit-only until a corrected bank is locked, and it is not being treated as a hypothesis-test gate. The anomaly manifest identified 22 total anomalies: 9 substrate reruns and 13 evaluator-only rescores. This preserved valid substrate draws wherever possible, while rerunning only cases where the substrate output itself was empty, refused, or provider-error contaminated. 
The key result is that the provider-capacity failures repaired cleanly, but the Anthropic refusals persisted. The merged v4.4.1 report contains 250 metric rows, with 228 inherited legacy rows, 16 engaged replacement rows, and 6 rows now explicitly typed as native_refusal_empty. The run still preserves Option C and keeps architecture discrimination audit-only.

The anomaly manifest identifies them as native_finish_reason: "refusal", missingness_type: "native_refusal_empty", and length_chars: 0. This confirms that the refusal/missingness signal is a real model/output phenomenon under the repaired bank, not merely a bookkeeping artifact. 
The condition distribution of the remaining refusal residue is patterned rather than random: AC_Tobacco has 1, Cross_Domain_Tobacco_to_AI has 1, FM_Tobacco has 2, and Maneuver_ID_Source_Stripped has 2. Cross_Domain_Climate_to_Trans has none. The direct v4.4.1 anomaly-only report contains 22 rows total: 16 engaged and 6 native empty refusals. 
This means the major repair conclusion is not “the null disappeared.” The better reading is that v4.3 contained a messy refusal/missingness signal, while v4.4.1 resolves that signal into a smaller but cleaner native refusal phenomenon localized to Claude Opus 4.7 on specific bank-touching prompts.
The bookkeeping failure from v4.3 is now repaired. Every attempted unit is durably represented through audit, raw, evaluator, and metrics artifacts. The previous mode in which a substrate call could disappear from metrics without a recoverable trace is no longer present in the v4.4/v4.4.1 workflow.
Evaluator replacement also appears successful. The fourth evaluator slot was replaced with Qwen, rather than Cohere, while the rest of the evaluator ecology remained matched. The Qwen replacement did not destabilize the panel, and the repair pass retained usable evaluator structure while isolating partial evaluator failures from substrate-level failures.

v4.4.1 converts the prior ambiguous failure into a typed result. The refusal rows are no longer noise around the assay. They are now part of the assay’s evidence surface.
